# Prepared demo records

The four-GET FastAPI app reads `UC1.json` and `UC2.json` directly. Edit the existing `document`, `imagery`, and `calculation` sections; changes take effect on the next request without modifying code or restarting the server. Use JSON numbers, not quoted numbers, and keep `case_id` unchanged.

UC2 document/calculation values are intentionally null. Replace every null in a section to enable its endpoint. Until then it returns HTTP 503 `case_not_ready`; UC2 imagery already works. Null is not treated as zero. A malformed record or invalid values returns HTTP 500 `invalid_prepared_data`.

## UC1 basis and limits

- Company/purchases are fictional agreed design values: Factory A, 5000 total tonnes, 30% from Area-1 (UC1), or 1500 tonnes. `purchase_from` is the display label; the underlying origin is `TH-DEMO-AOI-01`. Both purchase quantity fields are in tonnes.
- Calculations are the agreed prepared values based on rounded areas: maize area 216.23 ha; candidate-mask overlap 178.32 ha; uniform assumed yield 7 t/ha. Q = 1513.61 t; burn-linked share = 82.47 percent; C = 265.37 t. The endpoint reads these values unchanged.
- `burn_linked_percentage` uses 0–100, not a 0–1 ratio. The frontend adds the percent sign. Values are already rounded, so reconstructing C from rounded Q/b may differ slightly; do not recompute/overwrite them in the UI.
- The overlap calculation used the supplied UC1 maize geometry (`data/origins/gistda/usecase1/message.txt`, SHA-256 `c1edd717d66878e85482ead34b775ddf5f9151d194ea43d6e4fcfd3dc43d069f`) and the supplied native candidate mask. It excluded non-maize land and overlapping polygon duplicates.
- Mask dates: 2021-01-01 and 2021-03-12. Maize source update: 2026-09-30. This temporal mismatch means the spatial overlap is not a verified historical burned-maize percentage. The 7 t/ha yield is assumed, not measured. Burn-linked potential yield does not mean destroyed grain.
- This mask is a heuristic dNBR candidate mask, not a synthetic scenario or validated fire perimeter. There was no supplied cloud/scene-classification mask or independent perimeter validation. The runtime needs only these prepared values and images; it does not need the contributor's Downloads folder, native mask, ZIPs, or local processing packages.
- The demo returns prepared document fields, not actual PDF extraction, certification, or a misconduct/compliance verdict. No source PDF has been generated by this implementation.

## Images

Both image pairs are served byte-for-byte from `frontend/assets/selected-aois/`. Acquisition/source/permission metadata for the selected presentation files is not supplied in these records; retain that information in asset documentation when available. No metadata from the old v2 images is assumed. No new images or masks were generated or published by this backend work.
